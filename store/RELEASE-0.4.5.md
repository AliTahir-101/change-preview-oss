# ChangePreview 0.4.5

Fixes Reapply appearing when returning to an edited form after switching tabs or windows. The tracker now retains live-session state in the document, including after undo, Clear, and Reapply. Genuine reload recovery remains supported.

Includes all 0.4.4 tracking, UI, copy-button, export, and checkbox fixes. All 11 automated test suites pass, including tab/window return and actual-reload coverage.

After an unpacked update, reload the extension and refresh existing form pages before testing. Chrome Web Store submission remains pending; this GitHub release does not indicate store approval.
